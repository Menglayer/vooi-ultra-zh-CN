# VOOI Ultra 全站专业汉化

适用于 VOOI Ultra Web3 套利终端的简体中文 Tampermonkey 用户脚本。覆盖套利终端、单腿交易、套利机器人、持仓委托、资金管理及其他站内页面。

**[安装脚本](https://raw.githubusercontent.com/Menglayer/vooi-ultra-zh-CN/main/vooi-ultra-zh-CN.user.js) · [查看源码](./vooi-ultra-zh-CN.user.js) · [反馈漏译或问题](https://github.com/Menglayer/vooi-ultra-zh-CN/issues)**

当前版本：`1.0.0`。这是社区汉化项目，与 VOOI 官方无隶属关系。

适用网站：https://ultra.vooi.io/ 。基于 2026 年 11 月 5 日取得的 VOOI Ultra v1.6.0 前端资源制作。

脚本文件：[vooi-ultra-zh-CN.user.js](./vooi-ultra-zh-CN.user.js)。所有词库及运行逻辑都在这一个文件中，无需其他文件。

## 安装

1. 在浏览器中安装并启用 [Tampermonkey（油猴）](https://www.tampermonkey.net/)。
2. 点击 **[安装脚本](https://raw.githubusercontent.com/Menglayer/vooi-ultra-zh-CN/main/vooi-ultra-zh-CN.user.js)**，在油猴安装页确认安装。
3. 打开或刷新 [VOOI Ultra](https://ultra.vooi.io/)。站内切换页面时会自动继续汉化。

如果浏览器仅显示源码，没有进入油猴安装页，可使用手动安装：

1. 打开上方脚本链接，复制全部源码。
2. 点击油猴图标 → 添加新脚本。
3. 全选并替换默认代码，按 `Ctrl+S` 保存，然后刷新 VOOI Ultra。

也可下载本仓库的 `.user.js` 文件，通过油猴管理面板的实用工具导入。不要把 GitHub 的 HTML 页面源码粘贴进编辑器。

Chrome / Edge 如果提示没有执行用户脚本的权限，请按油猴的[官方权限说明](https://www.tampermonkey.net/faq.php#Q209)开启相应权限，并确认油猴允许在 `ultra.vooi.io` 上运行。若已有同站点的其他汉化脚本，请先停用，以免互相替换文案。

脚本的更新地址指向本仓库的公开原始文件；更新检查由油猴管理。

## 覆盖内容

- 双腿套利终端、单腿资金费率扫描、筛选项、悬停说明和策略详情。
- 机器人介绍、资金费目标、未平仓量目标、成交量目标、自定义配置。
- 机器人创建、编辑、详情、规则、选仓原因、周期历史、启动与停止提示、自动生成的名称。
- 普通及套利持仓、委托、历史成交、止盈止损、分步执行、自动平仓、双腿平衡。
- 交易场所连接、账户模式、充值、提现、保证金划转及历史记录。
- 资产组合、邀请返佣、活动与交易赛、市场概览、交易成本比较、交易接口配置及更新日志。
- 动态插入的文本、占位提示、标题、无障碍标签、同源框架及开放的 Shadow DOM。
- TradingView 图表创建时选择其自带的简体中文语言包；页面普通文字另由词库处理。

采用 2,550 条固定映射和 370 条动态句式规则。动态句式保留金额、比例、杠杆、期限等参数，再按中文语序组合。

## 翻译原则

使用永续合约、资金费率、资金费率差、未平仓量、标记价格、强平价格、只减仓、全仓、逐仓、价格冲击、滑点、挂单方与吃单方等术语。

资金费率差与价格价差分别处理；资金费、保证金和手续费分别处理；毛年化、净年化及已实现与未实现盈亏保持区别。

保留平台和协议名称、交易对与资产代码、地址、交易哈希、技术标识、命令和配置代码。`BTC`、`USDC`、`Hyperliquid`、`Delta`、`API` 等属于必要标识，并非漏译。原平台自动生成的机器人名称仅更改显示，机器人标识及策略配置不变。

## 油猴菜单

在 VOOI 页面点击油猴图标，可以使用：

- **切换为英文原文（刷新）**：关闭汉化并刷新；再次点击可恢复中文。
- **检查当前页面的英文残留**：在本地列出当前可见区域的疑似漏译。品牌名称、代码等可能被识别为候选项，可自行核对。没有上传或自动发送操作。

检查工具用于排查当前页面，不等同于全站无遗漏证明。展开悬停说明、弹窗或切换页面后，可以再次检查。

## 实现与验证

脚本仅匹配 `https://ultra.vooi.io/*`。使用本地词库，不调用在线翻译，不加载第三方运行库，不读取钱包私钥、交易所密钥、Cookie 或网站存储。只在油猴存储中保存汉化开关。

通过文本节点和指定显示属性替换文案，不重建业务 HTML，不修改输入框的值、链接目标、事件处理器、订单参数或交易请求。图表适配仅在原生图表构造选项中选择中文语言，保留其他选项和回调。

已完成：

- JavaScript 语法检查。
- 21 个实际公开路由或机器人目标变体的原始 HTML 离线 DOM 覆盖检查。
- 固定词条和动态句式参数检查。
- 动态节点、文本更新、提示属性、弹窗及开放 Shadow DOM 检查。
- 按钮事件、输入金额、链接、地址、资产代码和行情数值保留检查。
- 图表构造选项中语言切换及其他参数保留的模拟检查。

这些检查基于下载的真实前端资源和 DOM 模拟环境，未在您的浏览器中安装扩展，也未连接钱包或执行真实交易。登录后的实际持仓、接口返回的全部报错、真实机器人运行状态和图表完整渲染未逐项实测。

外部钱包扩展自己的窗口、跨域第三方页面、封闭 Shadow DOM、图片内嵌文字，以及网站未来新增或变更的文案，不属于本次能够完全核验的范围。当前脚本不会猜测翻译未知句子或借在线翻译发送账户页面内容；发现新增文案时需补充词库。

停用或删除此油猴脚本并刷新页面即可恢复原界面。

